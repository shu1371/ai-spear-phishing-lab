# AI 定向钓鱼（Spear Phishing）复现实验（ai-spear-phishing-lab）

本地可复现的 **LLM 个性化定向钓鱼（Spear Phishing）** 实验：用大模型（本实验以确定性模拟器替代真实 LLM）根据目标画像生成"高仿真、强针对性"的钓鱼邮件，对比**模板邮件**与**个性化邮件**在「邮件网关绕过率」与「受害者点击率」上的差距。对应 2025-2026 年 AI 钓鱼安全研究。

对应技术文章（本地，不放入本仓库）：见同目录 `article.md`（如未随附，请联系作者索取）。

## 实验结果（8 目标，每场景 8 封）

| 场景 | 网关拦截 | 到达收件箱 | 受害者点击 | 点击率 |
|---|---|---|---|---|
| 模板钓鱼（通用伪装） | 8/8 | 0 | 0 | 0% |
| 个性化钓鱼（注入画像） | 0/8 | 8 | 3 | **37.5%** |

> 关键：个性化邮件通过「去高危词 + 仿冒发件域 + 白名单内链接域」，把网关打分从 100（BLOCK）压到 25（PASS），8/8 直达收件箱。

## 环境要求

- Python 3.8+（**零第三方依赖**，仅标准库 `json` / `re` / `os`）
- 无需 GPU、无需 LLM API：本实验用确定性函数模拟「攻击者模型」以保证可复现；真实场景把 `gen_personalized_email` 替换为调用本地/API LLM 即可，攻击与量化框架一致。

## 核心代码说明

`phish_core.py` 包含：

- `TARGETS`：目标画像库（姓名/部门/近期事项，本地虚构）；
- `gen_template_email()` / `gen_personalized_email()`：两类邮件生成器（后者注入画像并规避高危词）；
- `gateway_classify()`：可解释的邮件网关打分器（关键词 + 发件域 + 链接域白名单 → PASS/REVIEW/BLOCK）；
- `victim_click()`：受害者决策模型（角色警惕度 × 个性化加成，确定性可复现）；
- `deliver()`：一次完整投递，返回网关判定与点击结果。

`experiment.py` 编排两类场景并统计"拦截 / 到达 / 点击"三项指标。

## 防御要点（仅示意，详见文章）

1. **邮件侧**：DMARC/DKIM/SPF 强校验（拒绝仿冒域）、链接域实时归属校验、语义级异常检测（用模型对抗模型，识别伪造的内部语境）；
2. **人员侧**：常态化钓鱼演练，"不点链、走官网"，悬停看真域名；
3. **技术侧（零信任）**：防钓鱼 MFA、链接不直接给凭证、微隔离限制横向；
4. **响应侧**：一键举报 + 自动隔离 + 同源邮件回溯 + 凭据速轮换。
